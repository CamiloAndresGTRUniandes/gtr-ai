# GTR-AI agent bootstrap
Extract into a staging folder and merge into D:\GTR-AI after reviewing conflicts. Do not overwrite existing AGENTS.md or other project files without merging. Start Codex from that root and ask it to read `AGENTS.md` and `prompts/02-local-codex-start.md`. The original Archive README and SHA256 manifest remain intact; new files are covered by BOOTSTRAP_SHA256SUMS. Keep `.spike-workspaces/`, `node_modules/`, credentials and local databases out of Git; merge these exclusions into any existing .gitignore. The bootstrap contains no production implementation and does not automatically run scripts. See docs/CONTINUITY.md for provenance and outstanding gates.
