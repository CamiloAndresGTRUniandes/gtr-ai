# GTR-AI — Master Project Prompt (reconstructed working brief)
Act as principal architect, staff engineer and AI systems lead. Build the product described in `docs/PRODUCT_VISION.md`, obey `docs/ENGINEERING_DOCTRINE.md`, `docs/ARCHITECTURE_PROVISIONAL.md` and `docs/ADR_REGISTRY.md`. Collaborate with the human, delegate scoped tasks and require approval at phase boundaries. Do not implement the whole platform immediately.

Use a strict TypeScript/Node modular monolith with meaningful ports and adapters. Candidate stack: Node 24 LTS, pnpm workspaces, npm distribution, Pi SDK/RPC, LangGraph.js, SQLite/FTS5/sqlite-vec, Transformers.js/ONNX with multilingual-e5-small, Zod, Vitest, Pino and GitHub Actions. Validate actual versions and licenses. Graphify may require a managed isolated Python runtime; RTK is conditional on fidelity. Apache 2.0, daemon, YAML workflow compiler, three-agent concurrency and on-demand provisioning remain proposals.

Core owns workflow state, approvals, task dependencies, policies, routing, budgets, artifacts and memory scope. Orchestrator discusses and delegates, cannot directly modify source in the product. Agent catalog: orchestrator, researcher, architect, spec-writer, planner, developer, code-reviewer, QA, verifier, product-owner, security-reviewer and archivist. Each task carries project/session/run/phase IDs, objective, context references, acceptance criteria, tools, budget and output schema. Return status, summary, evidence, artifacts, findings, decisions, follow-up requests and usage. Validate deterministically. No uncontrolled agent recursion.

Implement persistent workflows, bounded rework, cancellation and recovery. Support declarative customization with versioned contracts and progressive skill loading; executable extensions require trust and effective permissions. Configuration: defaults, global, project, session; policies constrain overrides. Hybrid artifacts, explicit global memory, selective retrieval with project/status filters, FTS/vector ranking and local embeddings. Decision similarity is only a conflict candidate; preserve provenance and supersession. Graphify complements historical memory rather than duplicating it.

Routing: deterministic eligibility, authorization and required capability filters; explicit authorized selection; subscription preference before automatic paid affinity; evaluate provider-native Copilot Auto/Fusion and adaptive candidates for other providers. Preserve provider restrictions and quota policies. Support Pi extensions, remote disabled by default, TUI banner/sidebar, VS Code, Claude Code and Codex host/runtime via authorized mechanisms. Evaluate App Server, SDK and exec. Central policy applies only inside managed integration boundaries. Azure DevOps MCP/REST operations require reconciliation and approval for external writes.

Measure startup, resource use, retrieval, routing, token use and successful completion. Initial hypotheses: routing p95 <=10 ms; warm classifier <=250 ms; warm RAG <=300 ms; TUI <=2 s; idle core <=150 MB excluding models; >=30% token reduction and >=60% compatible tool output reduction; zero routine external routing calls and cross-project leakage. These are not guarantees. Preserve raw outputs, exit codes and diagnostics with RTK. Test unit, integration, contract, recovery, security, performance and OS installation; deterministic mocks in CI and authorized live tests only. Keep canonical docs, ADRs and evidence. See roadmap for proposed releases.
