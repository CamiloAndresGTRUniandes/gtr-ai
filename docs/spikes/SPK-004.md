# SPK-004 — LangGraph

**Status:** OPEN — partial Apply/Verify evidence; not closed

## Technical question
Can the proposed LangGraph integration satisfy the master prompt requirements?

## Verified results
LangGraph 1.7.5 with `@langchain/langgraph-checkpoint-sqlite` 1.1.1 persisted a synthetic interrupt across processes — reported but not independently reproduced from committed raw evidence. Approve was reported to resume to `approved: true` and `implementation: 'done'`; reject to `approved: false` without implementation. These corrected outcomes are reported but not independently reproduced from committed raw evidence. The original script collision and stale assertion were corrected in the experimental script only.

Historical evidence remains under `../../evidence/`.

## Remaining acceptance criteria and limitations
Crash/replay windows, cancellation, task recovery, bounded rework, authenticated revision- and artifact-bound approvals, and durable final completion remain unverified. The flow is synthetic and does not establish production workflow authority. The checkpointer used nested `better-sqlite3` 12.11.1 (required as `^12.10.0`), distinct from the direct 13.2.0 vector comparison binding.

## Recommendation / fallback
Retain LangGraph as a candidate. Add a public regression test for persisted interrupt/resume, then extend it with crash/replay and approval-boundary scenarios before architecture selection.

## Security and licensing
No credentials, paid requests or external writes were used. Approval enforcement remains a high-risk open area.
