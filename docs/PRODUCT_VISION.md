# Product vision
GTR-AI is an open-source, local-first engineering platform with potential commercial capabilities. Its orchestrator collaborates with engineers, challenges decisions, plans and delegates scoped tasks to specialized agents. It is not an autonomous unrestricted coder. One npm installation should provision managed dependencies automatically; Node/npm and external authorized accounts remain prerequisites. Windows, Linux and macOS are required.

Required workflows: Full SDD (Research, Apply, Verify, Archive), Product Owner (Research, Define, Refine; epics, features, stories, bugs, technical debt, criteria), PR Reviewer (clean code, acceptance criteria, tests and evidence), QA Engineer (test design and automation using project frameworks), Planner (collaborative read-only planning until approved implementation). All phase boundaries require approval.

Required capabilities: shared central authority across Pi TUI, VS Code agent chat, Claude Code and Codex; Codex host and runtime candidate; configurable agents, skills and workflows; project-scoped persistent GTR-Mem plus explicit global memory; decision history and conflict candidates; local hybrid RAG; Graphify structural intelligence; Azure DevOps work items and PRs; multiple authorized subscriptions/providers and Copilot Auto/Fusion; embedded Ponytail; token-efficient routing and context. Git worktrees isolate concurrent modifications. See provisional architecture for detailed boundaries.
