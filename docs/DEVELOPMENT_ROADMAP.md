# Proposed development roadmap
Current gate: finish actual architecture validation. No production work until critical dependencies and security/recovery requirements are evidenced and approved.
- v0.1 Core Foundation: repository, contracts, configuration, CLI/process model, Pi, workflow engine, approvals, recovery, cross-platform CI.
- v0.2 Intelligent Engineering MVP: GTR-Mem, Planner, Full SDD, worktrees, Ponytail, routing, context and initial multi-provider support.
- v0.3 Developer Experience: TUI, validated RTK, metrics, extension management, expanded providers.
- v0.4 Engineering Ecosystem: Product Owner, PR Reviewer, QA, Azure DevOps, Graphify.
- v1.0 Cross-Host Platform: complete VS Code, Claude Code and Codex integrations, public extension contracts, installation and security hardening.
Architecture-critical integrations are investigated early regardless of release. This sequence is provisional and may change with evidence. Use `docs/UNBLOCK_PLAN.md` for the current execution order.
